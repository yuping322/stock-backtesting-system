使用方式 1: 单个计算器
  from src.factor.generator_v2 import create_factor_calculator
  
  calculator = create_factor_calculator('VOL10')
  result = calculator.calculate('000001', '2024-01-01', '2024-12-31')

使用方式 2: 批量生成
  from src.factor.generator_v2 import BuiltinFactorGenerator
  
  generator = BuiltinFactorGenerator(
      stock_codes=['000001', '000002'],
      start_date='2024-01-01',
      end_date='2024-12-31',
      factor_names=['VOL10', 'RSI_14', 'MA_20']
  )
  df = generator.generate()

使用方式 3: 错误处理
  from src.factor.generator_v2 import PartialResultError
  
  try:
      df = generator.generate()
  except PartialResultError as e:
      print(f"成功: {e.successful_count}, 失败: {e.failed_count}")

使用方式 4: 质量检查
  from src.factor.generator_v2 import DataQualityChecker
  
  result = DataQualityChecker.check_factor_output(df, ['VOL10'])
  DataQualityChecker.print_check_result(result, verbose=True)

🎯 关键特性:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 统一接口
   - 所有计算器都实现 calculate(stock_code, start_date, end_date)
   - 返回值统一为 pd.Series
   - 易于理解和使用

2. 异常体系
   - FactorGenerationException (基类)
   - DataNotAvailableError
   - FactorCalculationError
   - FactorValidationError
   - PartialResultError

3. 工厂函数
   - create_factor_calculator() 智能创建计算器
   - 支持优先级: file > func > name
   - 支持参数传递

4. 质量检查 (7 项)
   ① 必需列检查
   ② 数据类型检查
   ③ NaN 比例检查 (>70% 报错, >20% 警告)
   ④ 日均股票数一致性
   ⑤ 异常值检查 (3倍 IQR)
   ⑥ 日期连续性检查
   ⑦ 股票代码规范化

5. 工具支持
   - DataLoader: 数据加载抽象
   - DataProcessor: 数据处理工具
   - ConfigManager: 配置管理
   - ProgressTracker: 进度跟踪
