# 板块轮动统计打分与热度追踪 - Python脚本版本

这是一个A股板块轮动分析工具，用于分析板块热度和个股表现。

## 功能特点

- 自动过滤ST股和上市不足半年的新股
- 支持多种行业分类（申万、聚宽、证监会等）
- 计算N日收益率和板块热度得分
- 生成板块热度趋势图表
- 展示热门板块及板块内涨幅靠前的个股

## 使用方法

### 基本用法

```bash
# 使用默认参数运行
python sector_rotation_analysis.py

# 自定义参数运行
python sector_rotation_analysis.py 2025-11-11 sw_l2 5 10 5
```

### 参数说明

```
python sector_rotation_analysis.py [日期] [行业分类] [收益率天数] [回溯天数] [涨幅阈值]

参数：
- 日期: 分析日期，格式 YYYY-MM-DD，默认 2025-11-11
- 行业分类: 行业分类标准，可选值：
  * sw_l1: 申万一级行业
  * sw_l2: 申万二级行业 (默认)
  * sw_l3: 申万三级行业
  * zjw: 证监会行业
  * jq_l1: 聚宽一级行业
  * jq_l2: 聚宽二级行业
- 收益率天数: 计算收益率的天数，默认 5
- 回溯天数: 回溯分析的天数，默认 30
- 涨幅阈值: 涨幅阈值(%)，默认 30
```

### 示例

```bash
# 分析2025年11月11日申万二级行业的5日收益率，10天回溯，5%涨幅阈值
python sector_rotation_analysis.py 2025-11-11 sw_l2 5 10 5

# 分析证监会行业的10日收益率，20天回溯，20%涨幅阈值
python sector_rotation_analysis.py 2025-11-11 zjw 10 20 20
```

## 依赖要求

- Python 3.7+
- pandas
- numpy
- matplotlib
- jq_compat.py (项目内模块)

## 数据源

脚本使用项目内的数据源：
- 股票基本信息：通过 `jq_compat.get_all_securities()`
- 行业分类：通过 `jq_compat.get_industry()`
- 价格数据：通过 `data.load_oss_complex_stocks()`
- ST信息：通过 `jq_compat.get_extras()` （网络失败时自动跳过）

## 注意事项

- 确保项目数据源配置正确
- ST数据获取可能因网络问题失败，但不影响主要分析功能
- 图表文件会保存在当前目录下
- 首次运行可能需要较长时间加载数据（约1-2分钟）

## 性能优化建议

- 降低涨幅阈值可以获得更多有意义的板块数据
- 减少回溯天数可以加快计算速度
- 建议涨幅阈值设置为5-10%，回溯天数设置为10-30天
