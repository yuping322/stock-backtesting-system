# 版本对比

## train_super_factor.py (基础版)

**特点**:
- ✅ 简单快速
- ✅ 仅使用LightGBM
- ✅ 基础的特征处理
- ✅ 适合快速迭代

**适用场景**:
- 需要快速跑通流程
- 资源受限
- 对模型选择不敏感

## train_super_factor_v2.py (完整版) ⭐推荐

**特点**:
- ✅ 完整实现notebook所有功能
- ✅ 8种模型对比（KNN, 逻辑回归, 决策树, 朴素贝叶斯, 随机森林, AdaBoost, SVM, LightGBM）
- ✅ 多种特征选择方法（F检验, 互信息, 随机森林, RFE）
- ✅ 完整评估指标（Accuracy, AUC）
- ✅ 自动选择最佳模型
- ✅ 因子配置文件化

**适用场景**:
- 需要找到最佳模型
- 对模型效果要求高
- 有足够计算资源

## predict_stocks.py (预测脚本)

**特点**:
- ✅ 自动支持两种模型格式（基础版和完整版）
- ✅ 灵活的参数配置
- ✅ 输出标准格式的选股结果

**使用**:
```bash
python ml/predict_stocks.py --date 2024-10-24 --top-n 10
```

## 工作流程对比

### 基础版流程
```
数据获取 → 因子清洗 → LightGBM训练 → 保存模型
```

### 完整版流程
```
数据获取 → 因子预处理 → 创建标签 → 特征选择 
→ 训练8个模型 → 对比结果 → 选择最佳模型 → 保存
```

| 指标 | 基础版 | 完整版 |
|------|--------|--------|
| 训练时间 | ~5分钟 | ~20-30分钟 |
| 模型数量 | 1 | 8 |
| 特征选择 | ❌ | ✅ |
| 模型对比 | ❌ | ✅ |

## 如何选择？

### 选基础版如果：
- 💡 第一次使用
- 💡 想快速验证效果
- 💡 计算资源有限

### 选完整版如果：
- 💡 追求最佳效果
- 💡 有充足资源
- 💡 需要科学对比
- 💡 想完全复现研究结果

## 使用建议

1. **第一次**: 先运行完整版，了解各模型表现
2. **日常使用**: 用基础版快速训练和预测
3. **定期更新**: 每月用完整版重新对比，更新最佳模型
