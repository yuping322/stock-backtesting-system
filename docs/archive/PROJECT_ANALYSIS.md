# 股票回测系统项目分析报告

## 📊 项目概况

### 🎯 项目描述
这是一个**功能完整的股票回测系统**，基于 Python 技术栈构建，主要用于量化投资策略的回测验证和性能分析。

### 🏗️ 技术架构
```
核心技术栈：
├── Backtrader - 回测引擎框架
├── Streamlit - Web用户界面
├── AKShare - 实时金融数据获取
├── Alphalens - 因子分析
├── Pandas/NumPy - 数据处理
└── Matplotlib/Seaborn - 数据可视化
```

### 📁 项目结构
```
stock-backtesting-system/
├── integrated_backtesting_system.py  (2114行) - 主系统入口和Web界面
├── backtrader_base_strategy.py      (1099行) - Backtrader策略基类和工具函数
├── data.py                          (1592行) - 数据处理模块

├── env.sh.example                   - 环境变量配置模板

│   ├── *.csv                        - 预测数据文件

```

## ⚙️ 核心功能

### 🎯 策略支持
- **加权TopN策略** - 按权重选择表现最好的N只股票
- **等权重策略** - 等权重配置限定数量的股票
- **动量策略** - 基于动量因子的选股策略

### 📈 数据源
- **AKShare** - 实时获取股票和指数数据
- **本地CSV** - 支持导入本地预测数据文件
- **缓存机制** - 自动缓存数据和计算结果

### 📊 基准对比
支持多种基准指数：
- 沪深300 (sh000300)
- 上证指数 (sh000001) 
- 深证成指 (sz399001)
- 创业板指 (sz399006)
- 中证500 (sh000905)
- 上证50 (sh000016)

### 📉 性能分析
- **收益指标**: 总收益率、年化收益率、Alpha、Beta
- **风险指标**: 最大回撤、波动率、VaR、CVaR
- **效率指标**: 夏普比率、信息比率、索提诺比率
- **统计分析**: 胜率、连续盈亏、回撤恢复时间

### 🎨 可视化功能
- 净值曲线对比图
- 收益分布直方图
- 回撤分析图表
- 月度/年度统计表
- 持仓权重分布
- 交易记录明细

## 🔧 使用指南

### 1. 环境准备
```bash
# 克隆项目
git clone <repository-url>
cd stock-backtesting-system

# 创建环境变量文件（可选）
cp env.sh.example env.sh
# 编辑env.sh配置必要的环境变量
```

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 启动系统
```bash
# 方法一：使用启动脚本（推荐）
./start.sh

# 方法二：直接运行
streamlit run integrated_backtesting_system.py
```

### 4. 使用流程
1. 在Web界面选择数据文件或使用实时数据
2. 配置回测参数（初始资金、手续费等）
3. 选择策略类型和参数
4. 选择基准指数和分析指标
5. 点击"开始回测"运行分析
6. 查看综合摘要和详细分析结果
